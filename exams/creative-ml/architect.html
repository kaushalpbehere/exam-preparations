Q1. In the Transformer architecture, what is the core role of the Query, Key, and Value matrices? (A) Convolutional feature extraction (B) Backpropagation optimization (C) Calculating attention scores to weigh token importance (D) Defining the activation functions
Answer: C - Explanation: The Query and Key vectors compute a dot product (scaled and softmaxed) to generate attention weights. These weights are multiplied by the Value vectors to determine how much focus a token should place on other tokens in the sequence.
Q2. What is the main purpose of Retrieval-Augmented Generation (RAG)? (A) Enhancing a model's intrinsic vocabulary (B) Grounding generation by injecting external, up-to-date knowledge (C) Reducing the number of parameters in an LLM (D) Replacing the self-attention mechanism
Answer: B - Explanation: RAG retrieves relevant documents from an external vector database based on the user prompt, then concatenates that context into the LLM's prompt window, reducing hallucinations and improving factual accuracy.
