Q1. In MLOps, what describes a scenario where the statistical properties of the target variable (what the model predicts) change over time? (A) Data Drift (B) Concept Drift (C) Overfitting (D) Data Leakage
Answer: B - Explanation: Concept drift occurs when the fundamental relationship between the input features and the target variable changes over time, meaning the mapping the model learned is no longer valid. Data drift is when the distribution of the input features changes.
Q2. What is a core benefit of adopting a Continuous Training (CT) architecture in an MLOps pipeline? (A) Automatically tuning hyperparameters using grid search (B) Eliminating the need for model evaluation (C) Automatically retraining models on fresh data triggered by events or schedules (D) Compressing model artifacts for faster inference
Answer: C - Explanation: CT automates the retraining process by triggering a pipeline when performance degrades or on a schedule. This mitigates model staleness caused by drift and keeps the deployed model performing accurately over time.
