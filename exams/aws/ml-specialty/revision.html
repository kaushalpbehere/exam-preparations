AWS Machine Learning Revision Guide

Super-dense cheat sheet focusing on SageMaker, Bedrock, and ML Architecture.

1. Amazon SageMaker Ecosystem

  • SageMaker Studio: The centralized IDE for all ML steps. Replaces standalone notebook instances for heavy workflows.
  • Data Wrangler: Visual UI for data prep (cleansing, feature engineering) without code. Exports to pipelines.
  • Feature Store: Stores, retrieves, and shares ML features. Supports low-latency (<10ms) online retrieval for real-time inference and offline storage (S3) for batch training.
  • Clarify: Bias detection in training data and models. Feature attribution/explainability using SHAP values.
  • Model Monitor: Detects drift in production (Data drift, model quality drift, feature attribution drift, bias drift) by capturing endpoint requests/responses.
  • Debugger: Monitors training jobs in real-time. Detects vanishing gradients, overfitting, and un-optimized hardware usage.

2. Generative AI (Amazon Bedrock)

  • Amazon Bedrock: Serverless API access to Foundation Models (Anthropic Claude, Amazon Titan, Meta Llama).
  • Knowledge Bases (RAG): Connects FMs to private data (S3) via a vector database (e.g., OpenSearch Serverless). Automates embedding generation and chunking.
  • Agents for Bedrock: Executes multi-step tasks by allowing the LLM to call your company APIs (via Lambda and OpenAPI schemas).
  • Guardrails: Filters distinct from the FM's native safety. Blocks toxic content, redacts PII, and keeps responses on-topic based on corporate policy.

3. Storage, Ingestion, and Compute

  • Fast File Mode / Pipe Mode: Streams large datasets directly from S3 to SageMaker containers, saving local EBS volume space and reducing cold start time.
  • Amazon FSx for Lustre: Extremely high throughput, sub-millisecond latency file system. Ideal for massive CV/NLP deep learning workloads. Linked to S3.
  • AWS Inferentia & Trainium: Custom AWS chips offering the lowest cost-per-inference and cost-to-train for deep learning models.
  • Managed Spot Training: Uses spare EC2 capacity for up to 90% savings. Your training script MUST implement checkpointing (saving state to S3) to handle interruptions.

4. Endpoint Deployment Options

  • Real-time Endpoints: Best for low-latency, synchronous JSON payloads. Supports Auto-scaling (target tracking).
  • Multi-Model Endpoints (MME): Hosts thousands of similar models on a single endpoint/fleet to save cost. Models are dynamically loaded/unloaded from S3.
  • Serverless Inference: No instances to manage. Best for unpredictable, intermittent traffic. Charges per millisecond of compute. Subject to cold starts.
  • Batch Transform: Asynchronous processing for massive datasets (GBs/TBs) stored in S3. Spins up compute, processes the batch, writes back to S3, and tears down.
