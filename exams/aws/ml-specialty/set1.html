AWS ML Specialty & Associate

Academic Theory (MSc Level): Focus on AWS SageMaker distributed training, Bedrock GenAI integration, Retrieval-Augmented Generation (RAG) architectures, and vector embeddings using Amazon Titan.

Set 1 (Questions 1-50)

Q1. When using Amazon Titan embeddings in a RAG system, what mathematical operation is typically used to determine the similarity between the user query embedding and document embeddings? (A) Cross-entropy loss (B) Cosine similarity (C) Softmax function (D) Gradient descent
Answer: B - Explanation: Cosine similarity calculates the cosine of the angle between two multi-dimensional vectors, serving as a standard metric to determine semantic closeness in vector databases.
Q2. You are training a deep learning model on Amazon SageMaker. Which feature allows you to automatically stop a training job if the model's performance on the validation set stops improving? (A) SageMaker Debugger (B) Spot Instances (C) Managed Spot Training (D) Early Stopping with Hyperparameter Tuning
Answer: D - Explanation: Early Stopping monitors the validation objective metric during a hyperparameter tuning job and automatically terminates jobs that are not improving, saving time and cost.
Q3. You want to deploy multiple Machine Learning models to a single SageMaker endpoint to reduce infrastructure costs. What feature should you use? (A) Multi-Model Endpoints (MME) (B) SageMaker Autopilot (C) A/B Testing Endpoints (D) SageMaker Canvas
Answer: A - Explanation: MMEs allow you to host thousands of models on a single endpoint, sharing the underlying compute instances and dynamically loading models into memory.
Q4. To mitigate hallucination risks in generative models, a company requires human review for low-confidence ML predictions. Which service supports this workflow? (A) Amazon Augmented AI (A2I) (B) AWS Config (C) AWS Batch (D) Amazon CloudWatch
Answer: A - Explanation: Amazon A2I makes it easy to build human review workflows for ML predictions, routing low-confidence outputs to human teams for manual validation.
Q5. Which data processing framework does AWS Glue natively run under the hood for large-scale serverless ETL jobs? (A) Apache Flink (B) Apache Kafka (C) Apache Spark (D) Hadoop MapReduce
Answer: C - Explanation: AWS Glue uses a distributed Apache Spark environment natively to run serverless Extract, Transform, and Load (ETL) data pipelines.
Q6. Which service acts as a low-latency, scalable Graph database designed to find complex relationships in data, such as fraud rings? (A) Amazon Neptune (B) Amazon DocumentDB (C) Amazon Timestream (D) Amazon Aurora
Answer: A - Explanation: Amazon Neptune is a fully managed, high-performance graph database optimized for storing trillions of relationships and querying them with millisecond latency.
Q7. If you need a highly durable, object storage location to store ML model artifacts (like weights and biases) generated during SageMaker training, what do you use? (A) Amazon EBS (B) Amazon EFS (C) Amazon S3 (D) Amazon FSx
Answer: C - Explanation: Amazon S3 is the standard, highly durable object storage used by SageMaker for ingesting training datasets and storing the output model artifacts (model.tar.gz).
Q8. Which AWS capability helps clarify machine learning models by detecting potential bias and explaining individual predictions via SHAP values? (A) SageMaker Clarify (B) SageMaker Debugger (C) Model Monitor (D) Bedrock Evaluation
Answer: A - Explanation: SageMaker Clarify provides insights into model behavior by identifying data or model biases and generating feature importance explanations (SHAP values).
Q9. When utilizing Amazon Bedrock Agents, what acts as the bridge connecting the LLM to external APIs to execute real-world actions? (A) Action Groups mapped to AWS Lambda functions (B) CloudWatch Alarms (C) Route 53 DNS records (D) Amazon SQS Queues
Answer: A - Explanation: Agents use Action Groups equipped with OpenAPI schemas and Lambda functions to define the parameters the FM needs to extract to invoke external APIs.
Q10. You want to deploy an inference endpoint that updates its model weights dynamically without incurring any downtime. How do you approach this in SageMaker? (A) Delete the endpoint and recreate it (B) Use the `UpdateEndpoint` API with a new Endpoint Configuration (C) Manually SSH into the instance and swap files (D) Stop the instance, swap the S3 URI, and start it
Answer: B - Explanation: The `UpdateEndpoint` API performs a blue/green deployment natively, spinning up the new configuration and seamlessly shifting traffic without downtime.
Q11. Which Amazon S3 feature ensures that training datasets are completely unchangeable for compliance and auditing purposes? (A) S3 Versioning (B) S3 Intelligent-Tiering (C) S3 Object Lock (WORM) (D) S3 Transfer Acceleration
Answer: C - Explanation: S3 Object Lock enforces a Write-Once-Read-Many (WORM) model, preventing objects from being deleted or overwritten for a fixed amount of time or indefinitely.
Q12. When deploying an Amazon Bedrock model in a highly regulated industry, how do you ensure the API calls do not traverse the public internet? (A) By using an AWS WAF (B) By utilizing VPC Endpoints (AWS PrivateLink) (C) By encrypting data with AWS KMS (D) By deploying to a public subnet
Answer: B - Explanation: AWS PrivateLink provides private connectivity between VPCs and AWS services like Bedrock, keeping traffic strictly on the Amazon network without public internet exposure.
Q13. When evaluating an LLM's response quality against a human-written reference summary, which metric is most commonly used? (A) RMSE (Root Mean Square Error) (B) ROUGE (Recall-Oriented Understudy for Gisting Evaluation) (C) F1-Score (D) Log-Loss
Answer: B - Explanation: ROUGE measures the overlap of n-grams between the system-generated text and the reference text, standardly used for summarization evaluation.
Q14. You need to automate a workflow that invokes an Amazon Bedrock foundation model in response to an Amazon S3 file upload. Which service acts as the orchestration layer? (A) AWS Lambda (B) Amazon CloudFront (C) AWS Glue (D) Amazon EMR
Answer: A - Explanation: AWS Lambda can be triggered directly by S3 events, acting as the serverless compute layer to invoke the Bedrock API with the new data.
Q15. What is the primary function of Amazon SageMaker Feature Store? (A) To host pre-trained models (B) To provide a fully managed repository to store, update, retrieve, and share ML features (C) To visualize neural network architectures (D) To translate text across languages
Answer: B - Explanation: SageMaker Feature Store is a centralized repository for organizing ML features, supporting both low-latency online retrieval for inference and offline retrieval for training.
Q16. You are implementing a machine learning pipeline using SageMaker Pipelines. Which step type should you use to register a model in the Model Registry if it meets a specific accuracy threshold? (A) ProcessingStep (B) TrainingStep (C) ConditionStep (D) TuningStep
Answer: C - Explanation: A ConditionStep evaluates properties of previous steps (e.g., model evaluation metrics) and determines whether the pipeline should proceed to subsequent steps like model registration.
Q17. Which distributed file system is optimized specifically to deliver sub-millisecond latencies and massive throughput to EC2 instances for deep learning training? (A) Amazon S3 (B) Amazon FSx for Lustre (C) Amazon EFS (D) Amazon EBS
Answer: B - Explanation: FSx for Lustre is a high-performance file system integrated with S3, designed for compute-intensive workloads like fast ML training.
Q18. Your application uses RAG (Retrieval-Augmented Generation) with Amazon Bedrock. Which AWS service is natively integrated to act as a highly scalable vector database for semantic search? (A) Amazon RDS for MySQL (B) Amazon OpenSearch Serverless (Vector Engine) (C) Amazon DynamoDB (D) Amazon S3
Answer: B - Explanation: Amazon OpenSearch Serverless includes a vector engine specifically optimized for managing embeddings and executing rapid semantic similarity searches required for RAG architectures.
Q19. Which data format is highly recommended for parallel and distributed training jobs in Amazon SageMaker due to its optimized row/columnar structure and compression? (A) CSV (B) JSON (C) Parquet (D) Pipe mode with RecordIO-Protobuf
Answer: D - Explanation: Pipe mode streams data directly from S3 to the container in RecordIO-Protobuf format, reducing startup times and preventing the need to download the entire dataset to disk.
Q20. When processing highly unstructured text documents locally in Python, which open-source library is standard for orchestrating LLM tool chains and vector DB integrations? (A) TensorFlow (B) Scikit-Learn (C) LangChain (D) Pandas
Answer: C - Explanation: LangChain is a robust open-source framework specifically designed to simplify the creation of applications using large language models, including chains, agents, and memory.
Q21. Which AWS service provides a fully managed, scalable Apache Kafka cluster for streaming real-time event data into ML pipelines? (A) Amazon Kinesis (B) Amazon MSK (Managed Streaming for Apache Kafka) (C) Amazon SQS (D) AWS Step Functions
Answer: B - Explanation: Amazon MSK makes it easy to ingest and process streaming event data in real-time with Apache Kafka, which is widely used for building streaming ML pipelines.
Q22. Which service seamlessly integrates with Amazon Bedrock to provide short-term session memory for building conversational chatbot applications? (A) Amazon ElastiCache (B) Amazon S3 (C) AWS Glue (D) Amazon MSK
Answer: A - Explanation: Amazon ElastiCache (Redis/Memcached) is a high-speed, in-memory datastore perfect for maintaining low-latency conversational history and session states.
Q23. In the context of generative AI on AWS, what is a 'Knowledge Base' in Amazon Bedrock? (A) A static wiki page for documentation (B) A managed RAG capability connecting foundation models to internal company data sources (C) A SQL database for structured data (D) A predefined set of system prompts

Q24. Which Amazon SageMaker feature automatically builds, trains, and tunes the best machine learning models based on your data? (A) SageMaker Clarify (B) SageMaker Autopilot (C) SageMaker Debugger (D) SageMaker Neo

Q25. What role does AWS Identity and Access Management (IAM) play in securing Amazon Bedrock deployments? (A) Compiling foundation models (B) Controlling which users or applications can invoke specific foundation models (C) Connecting to on-premises databases (D) Encrypting vector embeddings
Answer: B - Explanation: IAM controls access to Bedrock APIs, ensuring that only authorized users, roles, and applications can list, view, or invoke specific foundation models.
Q26. In a neural network, what is the function of the Softmax layer? (A) To introduce non-linearity locally (B) To compress images (C) To convert a vector of raw scores (logits) into a calibrated probability distribution (D) To calculate the gradient of the loss
Answer: C - Explanation: Softmax normalizes the output of a network into a probability distribution over predicted output classes, where all values sum to 1.
Q27. Which AWS service is designed for real-time streaming analytics, allowing you to use SQL directly over incoming data streams? (A) Kinesis Data Analytics (Managed Service for Apache Flink) (B) Kinesis Data Firehose (C) Amazon Athena (D) Amazon Redshift

Q28. In the context of RAG, what is an 'embedding'? (A) A HTML snippet injected into a UI (B) A dense vector representation of text that captures semantic meaning (C) A physical server embedded in a local network (D) A cryptographic hash of a document
Answer: B - Explanation: An embedding maps text to a high-dimensional vector space where semantically similar phrases are mathematically close to each other.
Q29. Which container orchestrator can integrate directly with SageMaker for training and inference using Operators? (A) Docker Swarm (B) Amazon Elastic Container Service (ECS) (C) Amazon Elastic Kubernetes Service (EKS) (D) AWS Fargate

Q35. What metric does the 'Recall' performance evaluation measure in a binary classification ML problem? (A) The percentage of all predictions that were correct (B) The proportion of true positives out of all actual positive instances (C) The proportion of true positives out of all predicted positive instances (D) The loss function gradient
Answer: B - Explanation: Recall (or Sensitivity) measures a model's ability to correctly identify all actual positive cases (True Positives / (True Positives + False Negatives)).

Q49. If an Amazon SageMaker training job encounters an OutOfMemory (OOM) error on a GPU, what is the most immediate logical adjustment to the hyperparameters? (A) Increase the learning rate (B) Decrease the batch size (C) Change the activation function (D) Add more layers to the network
Answer: B - Explanation: Decreasing the batch size reduces the number of samples processed simultaneously, which directly reduces the memory footprint required on the GPU.
Q50. Which optimization technique helps a deep neural network generalize better by randomly ignoring a subset of neurons during training? (A) Batch Normalization (B) Gradient Clipping (C) Dropout (D) Data Augmentation
Answer: C - Explanation: Dropout is a regularization technique where randomly selected neurons are ignored during training, preventing complex co-adaptations and reducing overfitting.
