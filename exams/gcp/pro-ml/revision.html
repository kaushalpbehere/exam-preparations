GCP Revision Guide

1. General Cloud Knowledge

  • IaaS vs PaaS vs SaaS: Compute Engine (IaaS), Cloud Run (PaaS), Google Workspace (SaaS).
  • CapEx vs OpEx: Cloud shifts Capital Expenditure (buying servers) to Operational Expenditure (pay as you go).
  • Public vs Private vs Hybrid vs Multi-cloud: Anthos is GCP's multi-cloud/hybrid solution.
  • TCO (Total Cost of Ownership): Cloud reduces TCO by eliminating physical server maintenance.

2. General Google Cloud Knowledge

  • Regions & Zones: Regions are independent geographic areas (e.g., us-central1). Zones are isolated deployments within a region (e.g., us-central1-a).
  • Google's Network: GCP uses its own private global fiber network for fast, secure routing.
  • Pricing Calculator: Tool to estimate GCP costs before deployment.
  • Resource Hierarchy: Organization -> Folder -> Project -> Resources. Policies flow down.
  • IAM (Identity and Access Management): "Who" can do "What" on "Which resource".

3. Google Cloud Products and Services

  • Compute: Compute Engine (VMs), GKE (Kubernetes), Cloud Run (Serverless Containers), Cloud Functions (Event-driven Code).
  • Storage: Cloud Storage (Object/Blobs), Persistent Disk (Block for VMs), Filestore (NFS).
  • Databases: Cloud SQL (Relational), Cloud Spanner (Global Relational), Firestore (NoSQL Document), Bigtable (NoSQL Wide-column).
  • Data Analytics: BigQuery (Data Warehouse), Dataflow (Stream/Batch processing), Dataproc (Managed Hadoop/Spark), Pub/Sub (Messaging).
  • AI/ML: Vertex AI (Unified ML platform), Vision API, Natural Language API, Dialogflow.

4. Security, Billing, and Support

  • Shared Responsibility Model: Google secures the infrastructure; YOU secure your data and applications.
  • Billing Accounts: Must be linked to projects. Use Budgets and Alerts to prevent bill shock.
  • Support Plans: Basic (Free), Standard, Enhanced, Premium (15 min response).
  • Cloud Identity: Manage users and groups centrally.
  • Security Command Center: Centralized dashboard for security and risk management.
