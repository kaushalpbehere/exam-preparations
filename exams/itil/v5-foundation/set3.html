ITIL v5 Foundation

LAST-MINUTE CRAM (ITIL v5): Remember the focus on AI integration, automated service management, value streams, digital transformation, and advanced ITSM capabilities.

Set 3 (Questions 101-150)

Q101. What is the fundamental difference between an Incident and a Problem in ITIL v5? (A) Incidents are caused by hardware; problems are caused by software (B) An incident is a disruption to service; a problem is the underlying cause of one or more incidents (C) Incidents have workarounds; problems do not (D) There is no difference
Answer: B - Explanation: Incidents focus on restoring service (the 'what' is broken). Problems focus on identifying the root cause (the 'why' it broke) to prevent recurrence.
Q102. What is the primary focus of 'Supplier Management'? (A) Getting the cheapest price possible (B) Ensuring the organization's suppliers and their performances are managed appropriately to support the seamless provision of quality products and services (C) Replacing external suppliers with internal staff (D) Writing code for suppliers
Answer: B - Explanation: It focuses on value, relationship management, and ensuring suppliers meet agreed-upon service levels.
Q103. In ITIL v5, what role does a 'Service Broker' play? (A) They sell hardware (B) They act as an intermediary, assembling, integrating, and customizing services from multiple suppliers to present a unified service to the consumer (C) They are purely financial auditors (D) They write network protocols
Answer: B - Explanation: As multi-sourcing becomes common, the Service Broker manages the complexity of multiple suppliers on behalf of the business.
Q104. What is the primary objective of 'Release Management'? (A) To build the software code (B) To make new and changed services and features available for use (C) To physically install servers in a data center (D) To train users on new software
Answer: B - Explanation: While Deployment moves the code to production, Release Management (often involving feature toggles in v5) decides precisely *when* the user can access and use it.
Q105. How are 'Release' and 'Deployment' decoupled in modern ITIL v5 environments? (A) They must always happen at the exact same time (B) Code can be deployed to production (Deployment) but kept hidden behind a feature flag until the business is ready to launch it to users (Release) (C) Only managers release code (D) Deployment means rolling back
Answer: B - Explanation: Decoupling reduces risk. Code is safely deployed to the live environment silently. A 'Release' is simply turning on the feature flag.
Q106. What is 'Blue/Green Deployment' in the context of ITIL v5 Deployment Management? (A) Changing the UI colors (B) Maintaining two identical production environments; traffic is routed to one while the new version is deployed to the idle other, allowing for instant rollback if issues occur (C) Deploying only on Mondays (D) Deploying to mobile devices
Answer: B - Explanation: Blue/Green is a safe deployment strategy that minimizes downtime and provides a rapid rollback mechanism by maintaining two separate production environments.
Q107. Which deployment strategy gradually routes a small percentage of user traffic to a new version to monitor for errors before a full rollout? (A) Big Bang Deployment (B) Canary Release (or Canary Deployment) (C) Blue/Green Deployment (D) Waterfall Deployment
Answer: B - Explanation: Named after the canary in the coal mine, this strategy tests the new release on a small subset of users to identify issues before impacting everyone.
Q108. What is the goal of the 'Service Request Management' practice? (A) To resolve major incidents (B) To support the agreed quality of a service by handling all pre-defined, user-initiated service requests in an effective and user-friendly manner (C) To handle changes to core infrastructure (D) To write software bugs
Answer: B - Explanation: It manages standard requests (like password resets or software installation) efficiently, often via automated self-service portals.
Q109. Which concept focuses on minimizing manual intervention in Service Request Management? (A) Manual routing (B) Workflow Automation and Self-Service Portals (C) Telephone support (D) Wait-listed queues
Answer: B - Explanation: ITIL v5 heavily advocates for automating standard requests. A user requests software via a portal, and a script automatically installs it without human intervention.
Q110. How does 'Continual Improvement' apply to the Service Value Chain? (A) It only applies to the 'Deliver & Support' activity (B) It acts upon all activities of the Service Value Chain, driving improvement across all dimensions (C) It only applies to external vendors (D) It is a one-time activity during the 'Plan' phase
Answer: B - Explanation: Continual Improvement is pervasive. It must be applied to every practice, every dimension, and every step of the value chain.
Q111. What is an 'Information Security Incident'? (A) A printer running out of toner (B) Any event that compromises the Confidentiality, Integrity, or Availability of an information asset (C) A scheduled server reboot (D) A user requesting a new laptop
Answer: B - Explanation: This is a specific type of incident managed jointly by Incident Management and Information Security Management, dealing with breaches, malware, or unauthorized access.
Q112. In the context of the SVS, what role does 'Governance' play? (A) Micro-managing developers (B) Providing the means by which an organization is directed and controlled, ensuring alignment with organizational strategy and compliance (C) Writing code (D) Managing daily incidents
Answer: B - Explanation: Governance sets the rules, policies, and strategic direction, evaluating performance to ensure the organization meets its objectives legally and ethically.
Q113. What is 'Demand' in the ITIL Service Value System? (A) The final product delivered to a customer (B) The need or desire for products and services among internal and external consumers (C) The cost of a service (D) The physical hardware
Answer: B - Explanation: Demand is the input to the SVS. It is the trigger that initiates the activities within the Service Value Chain.
Q114. What is 'Opportunity' in the ITIL Service Value System? (A) A broken server (B) Options or possibilities to add value for stakeholders or otherwise improve the organization (C) An angry customer (D) A completed project
Answer: B - Explanation: Along with Demand, Opportunity is a key input to the SVS, representing chances to innovate or improve.
Q115. What does the 'Design and Transition' activity of the Service Value Chain ensure? (A) Daily user support (B) Products and services continually meet stakeholder expectations for quality, costs, and time to market (C) Strategic planning (D) Financial auditing
Answer: B - Explanation: This activity takes requirements and builds/transitions them into live environments safely and effectively.
Q116. Which Service Value Chain activity is responsible for ensuring components are available when and where they are needed, and meet agreed specifications? (A) Plan (B) Engage (C) Obtain/Build (D) Deliver and Support
Answer: C - Explanation: Obtain/Build acquires raw components (from suppliers or internal development) needed for service delivery.
Q117. Which practice involves reviewing and approving proposed changes to IT services? (A) Release Management (B) Change Enablement (C) Incident Management (D) Service Desk
Answer: B - Explanation: Change Enablement (formerly Change Management) assesses risk and authorizes changes before they are deployed.
Q118. What is a 'Change Authority'? (A) A piece of software (B) A person or group who authorizes a change (C) A regulatory body (D) A customer
Answer: B - Explanation: In modern agile environments, the Change Authority is often pushed down to the team level (peer review) rather than a centralized CAB for routine changes
Q119. How does ITIL v5 view the concept of 'Risk'? (A) Risk should be avoided entirely (B) Risk is only a negative concept (C) Risk is inevitable and must be managed; taking calculated risks is often necessary to achieve strategic objectives/value (D) Risk only applies to financial investments
Answer: C - Explanation: ITIL v5 acknowledges that innovation requires risk. The goal is to manage and mitigate risk, not paralyze the organization by trying to eliminate it entirely.
Q120. What is 'Swarming' in the context of ITIL v5 Incident Management? (A) Sending a massive amount of emails to users (B) A collaborative approach where multiple experts from different teams come together immediately to diagnose and resolve a complex incident, replacing traditional tiered escalation (C) A type of malware (D) Moving physical desks together
Answer: B - Explanation: Swarming avoids the delays of bouncing tickets between Tier 1, 2, and 3. Experts collaborate (often via ChatOps) until the issue is fixed.
Q121. What is 'Service Level Management' primarily concerned with? (A) Firing underperforming staff (B) Setting clear targets for service performance (SLAs and XLAs) and ensuring they are met through continuous monitoring and review (C) Buying new software (D) Managing network cables
Answer: B - Explanation: SLM negotiates the targets with the business and monitors IT's performance against those agreed targets.
Q122. Which practice ensures that an organization has the right mix of programs, projects, and products to execute its strategy within its funding constraints? (A) Incident Management (B) Portfolio Management (C) Service Desk (D) Capacity Management
Answer: B - Explanation: Portfolio management decides what investments to make to maximize business value.
Q123. What is the central artifact managed by the 'IT Asset Management' practice? (A) The Incident Queue (B) The Asset Register (C) The Knowledge Base (D) The Release Schedule
Answer: B - Explanation: The Asset Register tracks the lifecycle, financial cost, and licensing status of all IT assets.
Q124. 'Software Asset Management' (SAM) is a sub-practice of ITAM. What is its main goal? (A) Writing better code (B) Managing software licenses to ensure compliance and avoid over-purchasing or audit penalties (C) Deploying software to users (D) Fixing software bugs
Answer: B - Explanation: SAM is critical for financial management, ensuring the company isn't paying for unused licenses and isn't illegally using unlicensed software.
Q125. In terms of value creation, what is 'Utility'? (A) The price of a service (B) The functionality offered by a product or service to meet a particular need (What the service does) (C) The assurance that a service will meet agreed requirements (D) The physical hardware
Answer: B - Explanation: Utility means the service is 'fit for purpose'. It provides the features the user actually needs.
Q126. In terms of value creation, what is 'Warranty'? (A) A piece of paper coming with hardware (B) Assurance that a product or service will meet agreed requirements regarding availability, capacity, security, and continuity (How the service performs) (C) The functionality of the service (D) The cost of the service
Answer: B - Explanation: Warranty means the service is 'fit for use'. It might have the right features (Utility), but if it crashes every 10 minutes, it lacks Warranty.
Q127. A service must possess BOTH Utility and Warranty to: (A) Be expensive (B) Create value (C) Require a Service Desk (D) Be considered Agile
Answer: B - Explanation: Value is only realized when a service does what is needed (Utility) AND performs reliably and securely (Warranty).
Q128. What is 'Organizational Change Management' (OCM)? (A) Managing code changes in Git (B) The practice of ensuring that changes in an organization (processes, structure, culture) are smoothly and successfully implemented, and that the human side of change is managed (C) Changing the company's CEO (D) Replacing servers
Answer: B - Explanation: OCM focuses on the 'People' dimension, helping staff adapt to new tools, processes, or transformations to reduce resistance.
Q129. Why is ITIL v5 often described as being 'Framework Agnostic' or 'Complementary'? (A) Because it replaces all other frameworks (B) Because it is designed to integrate seamlessly with Agile, DevOps, Lean, and SRE rather than competing with them (C) Because it only works with Windows (D) Because it is an old framework
Answer: B - Explanation: ITIL v5 acts as an operating model that incorporates and elevates modern methodologies like DevOps and SRE to the enterprise level.
Q130. What is 'Lean' thinking applied to ITIL v5? (A) Firing staff to save money (B) Maximizing customer value while minimizing waste (unnecessary processes, delays, unused features) (C) Using thin client computers (D) Writing less code
Answer: B - Explanation: Lean principles are heavily integrated into ITIL v5, specifically in the 'Keep it simple and practical' and 'Optimize and automate' guiding principles.
Q131. A 'Major Incident' is: (A) Any incident affecting a VIP (B) An incident with significant business impact, requiring an immediate, coordinated, cross-team response (C) A scheduled outage (D) A bug in beta software
Answer: B - Explanation: Major incidents require special handling (often Swarming) because they cause severe disruption to critical business functions.
Q132. What is a 'Post-Incident Review' (PIR)? (A) Blaming the person who caused the outage (B) A blame-free analysis conducted after a major incident to determine the root cause, identify what went wrong, and implement systemic improvements to prevent recurrence (C) A financial audit (D) A user satisfaction survey
Answer: B - Explanation: Blame-free PIRs (or post-mortems) are a core SRE/DevOps practice adopted by ITIL v5 to drive continual improvement.
Q133. Which ITIL practice involves the systematic management of knowledge assets? (A) Incident Management (B) Knowledge Management (C) Asset Management (D) Release Management
Answer: B - Explanation: Knowledge Management aims to ensure the right information is delivered to the right place/person at the right time to enable informed decision-making.
Q134. How does ITIL v5 recommend treating documentation? (A) Write 500-page manuals for everything (B) Documentation should be 'just enough', maintained close to the work, and treated as code (e.g., Markdown versions in Git) (C) Documentation is useless in Agile (D) Hand-written notes only
Answer: B - Explanation: Agile documentation should be pragmatic, easily searchable, and updated as part of the normal workflow (Shift-Left).
Q135. What is 'Shift-Left' applied to Security (DevSecOps)? (A) Moving security checks to the very end of the project (B) Integrating automated security testing and policies directly into the CI/CD pipeline, catching vulnerabilities during coding rather than right before release (C) Outsourcing security (D) Ignoring security
Answer: B - Explanation: 'Shift-Left' means bringing a process (like security or testing) earlier in the lifecycle to catch defects when they are cheapest to fix.
Q136. What is the role of 'Architecture Management' in ITIL v5? (A) Designing buildings (B) Providing an understanding of all different elements that make up an organization, and how those elements interrelate (C) Managing local area networks only (D) Writing CSS
Answer: B - Explanation: Architecture management aligns IT infrastructure and software design with the overarching business strategy.
Q137. What is 'Technical Debt'? (A) Money owed to vendor suppliers (B) The implied cost of additional rework caused by choosing an easy (limited) solution now instead of using a better approach that would take longer (C) The cost of server power (D) A loan from a bank
Answer: B - Explanation: While sometimes necessary for speed to market, technical debt must be tracked and 'paid down' (refactored) to maintain system agility and stability.
Q138. Which practice ensures that services are delivered within agreed financial limits? (A) IT Asset Management (B) Service Financial Management (C) Capacity Management (D) Supplier Management
Answer: B - Explanation: Service Financial Management deals with budgeting, accounting, and charging requirements for IT services.
Q139. In Financial Management, what is 'Cloud FinOps'? (A) Buying cheap servers (B) A financial management discipline that enables organizations to get maximum business value from their variable cloud spending through cost visibility and optimization (C) A specific cloud provider (D) Avoiding the cloud entirely
Answer: B - Explanation: FinOps brings financial accountability to the variable spend model of cloud computing, often involving cross-functional teams.
Q140. What is 'Value Stream Mapping'? (A) Drawing a picture of an office (B) A Lean technique used to document, analyze, and improve the flow of information or materials required to produce a product or service for a customer (C) A network diagram (D) A database schema
Answer: B - Explanation: ITIL v5 uses Value Stream Mapping to identify bottlenecks, waste, and toil in processes to optimize how value is delivered.
Q141. A 'Service Desk' should ideally act as the 'Single Point of Contact' (SPOC). Why? (A) To hide IT from the business (B) To provide a consistent, clear, and efficient communication channel for all users, preventing them from bypassing processes and contacting engineers directly (C) To slow down requests (D) To track user internet usage
Answer: B - Explanation: A SPOC ensures all incidents and requests are properly logged, prioritized, and routed, protecting engineers from constant interruption.
Q142. What is a 'Standard Operating Procedure' (SOP)? (A) A complex coding language (B) A documented set of step-by-step instructions compiled to help workers carry out routine operations efficiently and uniformly (C) A legal contract (D) A hardware manual
Answer: B - Explanation: SOPs are crucial for Knowledge Management and for standardizing repeatable tasks so they can eventually be automated.
Q143. Which ITIL v5 practice is focused on matching the workforce's skills to the organization's needs? (A) Workforce and Talent Management (B) Service Desk (C) Incident Management (D) Change Enablement
Answer: A - Explanation: This practice ensures the organization has the right people with the right skills and knowledge to support its objectives.
Q144. What characterizes a 'T-shaped' professional, a concept often endorsed in ITIL v5 and Agile? (A) Someone who only knows one specific thing (B) Someone who possesses deep expertise in one specific area (the vertical bar) but also has broad knowledge across many disciplines to facilitate collaboration (the horizontal bar) (C) Someone who works part-time (D) A manager
Answer: B - Explanation: T-shaped individuals break down silos because their broad knowledge allows them to communicate effectively with other specialists.
Q145. What is the overarching goal of integrating AI into ITIL v5 practices? (A) To eliminate all human jobs (B) To increase human cognitive capacity, automate toil, predict failures, and provide a superior, personalized user experience (C) To generate random data (D) To replace the Service Desk entirely without fallback
Answer: B - Explanation: AI is an enabler. It augments human analysts by handling repetitive noise and providing data-driven insights, allowing humans to focus on complex problem-solving.
Q146. How does 'Continual Improvement' relate to 'Technical Debt'? (A) They are unrelated (B) Continual Improvement cycles should explicitly allocate time to track, manage, and reduce Technical Debt to ensure long-term service sustainability (C) Continual improvement increases technical debt (D) Technical debt prevents continual improvement
Answer: B - Explanation: Managing technical debt is a core component of continually improving the stability and agility of IT environments.
Q147. What is 'Dark Launching' in Deployment Management? (A) Deploying code illegally (B) Deploying a new feature to production but hiding it from the UI, allowing it to be tested against live traffic (e.g., database queries) before the user knows it exists (C) Shutting down servers (D) Using dark mode UI
Answer: B - Explanation: This is an advanced deployment strategy used to test the performance impact of new code under real production load without risking user experience.
Q148. Which Service Value Chain activity ensures that services are operated and maintained according to agreed specifications? (A) Plan (B) Design and Transition (C) Deliver and Support (D) Obtain/Build
Answer: C - Explanation: 'Deliver and Support' is where Incident Management, Service Desk, and routine operational activities live.
Q149. What is the definition of an 'IT Service'? (A) Just a piece of software provided to a user (B) A means of enabling value co-creation by facilitating outcomes that customers want to achieve, without the customer having to manage specific costs and risks (C) A physical server hosted in a datacenter (D) The IT department itself
Answer: B - Explanation: This is the fundamental definition. IT provides the capability (e.g., email), absorbing the underlying complexity and hardware risk, so the business can just achieve its outcome (e.g., communicating).
Q150. According to ITIL v5, what must an organization do before automating a process? (A) Buy the most expensive tool (B) Optimize the process to eliminate waste and unnecessary steps; automating an inefficient process just creates inefficiency faster (C) Ask the CEO for permission (D) Train everyone on Python
Answer: B - Explanation: The guiding principle is 'Optimize and Automate'. You must apply Lean thinking to simplify the process before applying technology to automate it.
