Azure ML Path (DP-100)

Key Focus (2026): Azure ML SDK v2, MLflow integration, Managed Online Endpoints, Automated ML, and Responsible AI paradigms.

Set 2 (Questions 1-50)

Q1. You are performing a data preparation step that requires a highly distributed, big data platform utilizing Apache Spark. Which Azure service integrates seamlessly with Azure ML for this task? (A) Azure SQL Database (B) Azure Cosmos DB (C) Azure Synapse Analytics or Azure Databricks (D) Azure App Service
Answer: C - Explanation: Azure Synapse Analytics (Synapse Spark pools) and Azure Databricks provide massive Spark computing power and integerate directly with Azure ML workspaces for seamless data-prep to ML training pipelines.
Q2. Which Azure feature provides a centralized identity management system, allowing a Compute Cluster to authenticate to Azure Blob Storage securely without embedding passwords in code? (A) Azure Key Vault Secrets (B) Managed Identities (System-assigned or User-assigned) (C) Local Administrator accounts (D) Shared Access Signatures (SAS) in GitHub
Answer: B - Explanation: Managed Identities allow Azure resources (like a compute cluster) to authenticate to other Azure services (like Storage or Key Vault) securely using Azure AD, eliminating credentials from code.
Q3. What Azure service acts as the underlying secure key vault for storing secrets (like database passwords) associated with an Azure Machine Learning workspace? (A) Azure Security Center (B) Azure Key Vault (C) Azure Active Directory (D) Managed Identity
Answer: B - Explanation: When an Azure ML Workspace is created, an Azure Key Vault is automatically provisioned to securely store secrets, connection strings, and access keys used by the workspace.
Q4. Why might you use the `fairlearn` open-source package (integrated with Azure ML) alongside your trained classification model? (A) To improve the UI design (B) To assess if the model exhibits disparate impact or bias across different demographic groups (like gender or age) and apply mitigation algorithms (C) To serialize the model to ONNX (D) To compress the dataset
Answer: B - Explanation: Fairlearn provides metrics and mitigation algorithms to evaluate models for fairness, ensuring predictions do not unfairly disadvantage specific sensitive groups, fulfilling Responsible AI mandates.
Q5. If you need to distribute deep learning training across multiple GPUs using PyTorch, which communication backend is commonly specified in the Azure ML Command Job configuration? (A) MPI or NCCL (B) HTTP (C) FTP (D) SMTP
Answer: A - Explanation: For distributed PyTorch training, the process relies on NCCL (NVIDIA Collective Communication Library) to communicate between GPUs, often coordinated via MPI (Message Passing Interface).
Q6. During AutoML, the system applies data guardrails. What is the purpose of the 'Class balancing detection' guardrail? (A) To randomly delete data until classes are equal (B) To alert the user if the training dataset is heavily skewed toward one class, which may lead to biased predictions (C) To add noise to images (D) To switch from classification to regression
Answer: B - Explanation: Data guardrails automatically check the input data for potential issues. The class balancing guardrail flags highly imbalanced datasets so the user is aware the resulting model could be biased.
Q7. In Azure ML SDK v2, which object wraps your code, environment, and compute to execute a specific task, such as training a Python script? (A) A Workspace (B) An Environment (C) A Command Job (D) A Component
Answer: C - Explanation: In SDK v2, a 'Command Job' is the fundamental execution unit that runs a specific command (like `python train.py`) within a specified Environment on a designated Compute target.
Q8. Which library enables you to programmatically define Azure ML resources (like jobs, endpoints, datasets) declaratively using YAML files and a command-line interface? (A) Azure ML SDK v1 (B) Azure CLI with the `ml` extension (v2) (C) Bicep exclusively (D) PowerShell
Answer: B - Explanation: The Azure CLI `ml` extension (CLI v2) allows data scientists and engineers to define and manage ML resources using declarative YAML files, fully supporting MLOps CI/CD pipelines.
Q9. When deploying a model as a real-time web service in Azure ML for high-scale, production scenarios, which target is generally recommended? (A) Azure Container Instances (ACI) (B) Azure Kubernetes Service (AKS) (C) Managed Online Endpoint (D) Both B and C are suitable for high scale
Answer: D - Explanation: For production, real-time deployments that require high scale, autoscaling, and secure authentication, AKS or Managed Online Endpoints are the recommended deployment targets.
Q10. What is the primary difference between a 'Data Asset' and a 'Datastore' in Azure Machine Learning? (A) A datastore stores the physical data; a data asset is a reference to a specific file or folder in a datastore. (B) They are identical concepts in v2. (C) A data asset is an external database (like SQL); a datastore is internal. (D) Data assets are only used for images; datastores are for tabular data.
Answer: A - Explanation: While a Datastore is the connection to the storage service itself, a Data Asset is a named reference (with versions) pointing to a specific file, folder, or SQL query located within that Datastore.
Q11. Which Azure ML artifact primarily encapsulates the actual learned weights/parameters of an algorithm after a training job completes? (A) An Environment (B) A Data Asset (C) A Model Asset (D) A Component
Answer: C - Explanation: A Model Asset registers the physical files (like a .pkl, .pt, or .onnx file containing learned weights) and accompanying metadata in the workspace registry.
Q12. You require a compute target that can securely access data located strictly within your company's on-premises network via a VPN. Which setup is appropriate? (A) An Azure ML Compute Cluster deployed within your Azure Virtual Network (VNet) that is peered to on-premises (B) A standard public Compute Instance (C) Azure Databricks on the public internet (D) AutoML managed compute
Answer: A - Explanation: By deploying the Compute Cluster into an Azure Virtual Network (VNet), and connecting that VNet to your on-premises network via ExpressRoute or VPN, the cluster can access private local data.
Q13. You want to automate the selection of the best-performing model algorithm and hyperparameters for a classification dataset. Which Azure ML feature should you use? (A) Azure Machine Learning Designer (B) Automated Machine Learning (AutoML) (C) MLflow Tracking (D) Azure ML Pipelines
Answer: B - Explanation: Automated Machine Learning (AutoML) automates the iterative tasks of machine learning model development, exploring different algorithms and hyperparameters to find the optimal model.
Q14. If data is highly imbalanced in a classification problem, which evaluation metric provides a more reliable picture of model performance than raw 'Accuracy'? (A) Mean Absolute Error (MAE) (B) Area Under the Precision-Recall Curve (PR AUC) or F1-Score (C) R-Squared (D) Root Mean Square Error (RMSE)
Answer: B - Explanation: For imbalanced datasets, Accuracy can be misleading. PR AUC or F1-Score (harmonic mean of precision and recall) focus specifically on the model's ability to identify the minority positive class.
Q15. What is the role of an Azure Container Registry (ACR) when linked to an Azure Machine Learning workspace? (A) It stores tabular datasets (B) It hosts the user interface for ML Studio (C) It builds, stores, and manages Docker container images used for training environments and deployments (D) It acts as the relational database for MLflow tracking
Answer: C - Explanation: Azure ML relies on ACR to store the customized Docker images used to spin up training jobs or serve models as REST endpoints.
Q16. When setting up Data Drift monitoring for an endpoint, which two datasets are compared? (A) The Validation set vs the Test set (B) The original Training (Baseline) dataset vs the new Production Inference data (C) Text data vs Image data (D) Two different models' outputs
Answer: B - Explanation: Data Drift evaluates if the statistical distribution of the live inference data is significantly diverging from the baseline dataset originally used to train the model.
Q17. In an NLP scenario, what is the primary benefit of using a pre-trained Azure OpenAI foundational model rather than training a language model from scratch in Azure ML? (A) It requires writing more custom C++ code (B) It drastically reduces training time, cost, and requires significantly less labeled data for state-of-the-art results (few-shot learning) (C) It allows complete ownership of the base model weights (D) It runs natively on your laptop without the cloud
Answer: B - Explanation: Foundational models provided by Azure OpenAI are pre-trained on vast amounts of data, allowing developers to leverage them via APIs with minimal configuration or fine-tuning, saving immense resources.
Q18. You are building an Azure ML Pipeline. If you want a specific step to only run if a previous step generates a certain output (e.g., metric > 0.8), how is this managed in SDK v2? (A) Using a PipelineComponent (B) You cannot have conditional logic; you must split the pipeline (C) Using `mldesigner.component` and Python conditional statements in the pipeline function (D) Using Azure Data Factory instead
Answer: C - Explanation: In SDK v2, pipelines are often defined using Python functions decorated with `@pipeline`. You can use control flow (like `if` statements) over component outputs if supported by the runtime, though complex conditional logic is often offloaded to Azure Logic Apps or orchestrators.
Q19. Which Azure ML tracking URI should you set when using MLflow to log metrics and artifacts directly to your Azure ML workspace? (A) The Azure Blob Storage connection string (B) The Azure ML Workspace MLflow tracking URI (C) A generic SQLite database URL (D) The Azure Monitor endpoint
Answer: B - Explanation: To natively log MLflow runs into Azure ML, you configure the MLflow tracking URI to point to the specific tracking URL generated by your Azure ML workspace.
Q20. You have trained a PyTorch model and want to optimize it for faster inference with a smaller memory footprint on specific hardware. Which Azure ML-supported tool enables this? (A) ONNX (Open Neural Network Exchange) (B) Fairlearn (C) InterpretML (D) MLflow Registry
Answer: A - Explanation: ONNX is an open format for representing ML models. Azure ML encourages converting models to ONNX to optimize inference performance across various hardware platforms.
Q21. You are utilizing Azure Machine Learning Designer. What is the standard visual representation of a data processing or training step? (A) A Jupyter Cell (B) A Node/Module connected by edges (C) A bash script (D) A YAML file
Answer: B - Explanation: Azure ML Designer provides a drag-and-drop visual interface where operations are represented as nodes (modules) connected to form a pipeline graph.
Q22. During a hyperparameter tuning process (Sweep Job), which early termination policy allows you to conserve resources by terminating runs whose primary metric falls outside the top X percent of completed runs? (A) Bandit Policy (B) Median Stopping Policy (C) Truncation Selection Policy (D) Random Search
Answer: C - Explanation: The Truncation Selection Policy cancels a given percentage of the lowest-performing runs at specified evaluation intervals.
Q23. Which of the following is an Azure Cognitive Service designed specifically to extract printed text, handwriting, and data from scanned documents or PDFs? (A) Face API (B) Speech to Text (C) Azure AI Document Intelligence (formerly Form Recognizer) (D) Immersive Reader
Answer: C - Explanation: Azure AI Document Intelligence leverages advanced ML models to extract text, key-value pairs, tables, and structures from documents.
Q24. If you need a low-code approach exclusively for developing a computer vision model in Azure, what Azure Cognitive Service capability integrates tightly with Azure ML concepts? (A) Azure Custom Vision (B) Text Analytics API (C) Form Recognizer (D) Bot Framework
Answer: A - Explanation: Azure Custom Vision provides an accessible interface to upload images, tag them, and train custom image classification or object detection models quickly.
Q25. You need to deploy a model that processes large batches of data asynchronously (e.g., scoring millions of rows overnight). Which endpoint type should you use? (A) Managed Online Endpoint (B) Managed Batch Endpoint (C) Azure Kubernetes Service (AKS) Online Endpoint (D) Container Instance (ACI)
Answer: B - Explanation: A Managed Batch Endpoint is specifically designed to distribute and execute scoring of large datasets asynchronously across compute clusters.
Q26. Which sampling method for hyperparameter tuning (Sweep Job) evaluates all possible combinations of the defined hyperparameter space? (A) Random Sampling (B) Grid Sampling (C) Bayesian Sampling (D) Sobol Sampling
Answer: B - Explanation: Grid Sampling performs an exhaustive search over all possible combinations of the specified hyperparameter values.
Q27. If a Data Scientist wants to experiment with features offline using a local Python IDE before pushing to the cloud, how can they authenticate locally to the Azure ML Workspace? (A) Using `DefaultAzureCredential` from `azure.identity` which picks up local Azure CLI login tokens (B) By SSHing directly into the workspace API (C) They cannot; development must happen in the cloud (D) By disabling IAM
Answer: A - Explanation: When authenticated locally via `az login`, the `DefaultAzureCredential` allows the MLClient to securely authenticate and interact with Azure ML resources directly from a local IDE.
Q28. When deploying a blue-green update to an Azure ML Managed Online Endpoint, what is the purpose of traffic splitting? (A) To balance load evenly across all world regions (B) To direct a specific percentage of inference requests (e.g., 10%) to the new 'green' deployment to test it safely before fully switching (C) To split a large dataset into training and validation sets (D) To prevent DDoS attacks
Answer: B - Explanation: Traffic splitting natively supports safe rollouts by allowing you to route a fraction of live traffic to a new model version (deployment) to monitor its performance before shifting 100% of the traffic.
Q29. Which Azure ML deployment feature ensures that your real-time endpoint automatically allocates more compute nodes when traffic spikes, and scales down when idle? (A) Autoscaling (B) Data Drift detection (C) Traffic Splitting (D) Online Testing
Answer: A - Explanation: Autoscaling policies can be configured on Managed Online Endpoints (or AKS) to dynamically adjust the number of instances based on CPU utilization or request queues.
Q30. You want to monitor a deployed model in production for 'Data Drift'. What specifically are you measuring? (A) Changes in the underlying source code of the application (B) The difference in distribution between the training dataset and the actual inference dataset over time (C) Hardware degradation of the cluster (D) Security breaches on the endpoint
Answer: B - Explanation: Data Drift occurs when the statistical properties of the incoming production data change significantly from the data used to train the model, potentially degrading accuracy.
Q31. An Azure ML Sweep Job using Bayesian Sampling is restricted from using which early termination policy? (A) Bandit (B) Median Stopping (C) Early termination policies are entirely unsupported with Bayesian Sampling (D) Truncation Selection
Answer: C - Explanation: Bayesian Sampling does not support early termination policies in Azure ML because it relies on the results of previous runs to inform the selection of the next hyperparameters.
Q32. Which feature of Azure Machine Learning allows you to define reusable pieces of code (with defined inputs and outputs) that can be easily strung together into a Pipeline? (A) Components (B) Sweeps (C) Environments (D) Datastores
Answer: A - Explanation: Components are self-contained, modular pieces of code that define a step in a machine learning pipeline, complete with inputs, outputs, and an execution environment.
Q33. When utilizing a Compute Instance in Azure ML, what is its primary use case? (A) Running massive, distributed training pipelines over several days (B) Serving production models with auto-scaling capabilities (C) Acting as a cloud-based development workstation for data scientists to run notebooks (D) Archiving old datasets
Answer: C - Explanation: A Compute Instance is a fully managed, cloud-based workstation designed primarily for development, running Jupyter/VS Code, and executing interactive data exploration.
Q34. What is the primary benefit of 'Local Mode' when using MLflow and the Azure ML SDK v2? (A) It provisions 100 GPUs instantly (B) It allows you to run and debug the exact training logic and container abstraction on your local PC before securely submitting it to the cloud (C) It prevents data from ever reaching the cloud (D) It disables tracking entirely
Answer: B - Explanation: Local run modes facilitate rapid prototyping and debugging by executing the script in its designated container environment on the local machine before spending time queueing on a cloud cluster.
Q35. You are creating a compute target in Azure ML specifically designed for distributed training of deep neural networks. Which compute type should you provision? (A) Compute Instance (B) Compute Cluster (C) Inference Cluster (D) Attached Compute
Answer: B - Explanation: An Azure ML Compute Cluster is a managed-compute infrastructure that enables distributed training of models across a cluster of CPU or GPU nodes, automatically scaling up and down.
Q36. When using MLflow with Azure ML, an active `run` automatically tracks metrics. How do you log a specific accuracy value (e.g., 0.95)? (A) `mlflow.log_metric("accuracy", 0.95)` (B) `print("accuracy: 0.95")` (C) `mlflow.save_artifact("accuracy.txt")` (D) `azureml.core.Run.log_value(0.95)`
